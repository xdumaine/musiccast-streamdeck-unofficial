Help

Use the fixed LAN address of your MusicCast device (port 80). Device IP, zone, and shared colors apply across all MusicCast actions. API base: http://<host>/YamahaExtendedControl/v1/…. Zone is usually main; use system/getLocationInfo for multi-zone amps. Note: Play, play/pause, stop, previous, and next send MusicCast netusb/setPlayback commands. They work for network/USB/streaming sources, but they cannot start or stop a physical turntable/phono input.
