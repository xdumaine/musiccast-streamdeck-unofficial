Help

Device IP, zone, and shared colors apply across all MusicCast actions. Use comma-separated MusicCast input IDs for Source buttons and dials. The key cycles forward on press; the dial rotates backward/forward through the list and refreshes on push or touch. The button icon updates from getStatus.input. Common IDs include phono, airplay, bluetooth, net_radio, spotify, server, and usb. Supported inputs vary by device.
