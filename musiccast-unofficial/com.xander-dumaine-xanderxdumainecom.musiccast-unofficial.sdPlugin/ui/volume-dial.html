Rotate adjusts volume. Push toggles mute; double-push toggles power. Choose Level bar for a rounded 0–100% strip (4px corner radius). Adjust Bar thickness when using bar display. Squiggle bar draws a static wavy fill instead of a solid fill. In squiggle mode, thickness controls line weight while amplitude can use the full bar slot height; use wavelength for spacing. Expand Colors to customize the touch strip palette. Background refresh is slow by design; dial rotation, mute, and power update the display immediately.
